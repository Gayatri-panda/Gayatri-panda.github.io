# Gayatri-panda.github.io

🌐 **Personal Portfolio Website** - Hosted on GitHub Pages

## 🚀 Overview

This is my personal portfolio website showcasing my projects, skills, and contact information. Built with clean HTML, CSS, and JavaScript for a modern, responsive design.

## ✨ Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI** - Clean, professional design with gradient accents
- **Smooth Animations** - Scroll animations and hover effects for better UX
- **Projects Showcase** - Display your GitHub projects with descriptions and links
- **Contact Section** - Easy ways for visitors to get in touch

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- JavaScript (Vanilla)
- Font Awesome Icons

## 📝 Customization

To personalize this portfolio for yourself:

1. **Update Personal Information** in `index.html`:
   - Change the name in the hero section
   - Update the bio in the About section
   - Modify skills in the Skills & Technologies section

2. **Add Your Projects**:
   - Edit the project cards in the Projects section
   - Add links to your actual GitHub repositories
   - Update project descriptions and tags

3. **Update Contact Information**:
   - Replace placeholder email addresses
   - Add your LinkedIn, Twitter, and other social media links

4. **Customize Colors** in `styles.css`:
   - Modify the CSS variables in the `:root` section
   - Change `--primary-color` and `--secondary-color` to your preferred colors

## 🌐 Viewing the Site

Once deployed, your site will be available at: `https://gayatri-panda.github.io`
